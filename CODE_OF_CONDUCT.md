# Code of Conduct

This project follows a contributor-friendly standard of respectful, inclusive, and professional collaboration. Crafting Kit is a strict, evidence-driven engineering project; conduct expectations match.

## Expected behavior

- Be respectful and constructive.
- Assume good intent while addressing concrete behavior, not character.
- Keep discussions focused on the project, the source, and the evidence.
- Cite files, lines, commits, and run output when discussing problems.
- Disagree on technical merits. Use ADRs/RFCs (see [`prompt-system/adrs/`](prompt-system/adrs/), [`docs/09_adr_rfc_style_guide.md`](docs/09_adr_rfc_style_guide.md)) when consensus needs a record.

## Unacceptable behavior

- Harassment, abuse, discrimination, or personal attacks.
- Sustained disruption of issues, PRs, or discussions.
- Publishing private information of contributors or users.
- Posting real secrets, customer data, PII, or production logs in public spaces. (See [`SECURITY.md`](SECURITY.md).)

## Reporting

Report concerns to the project maintainer (see [`GOVERNANCE.md`](GOVERNANCE.md) for the current maintainer). Maintainers may:

- request edits to comments or PRs
- close or lock issues / PRs that violate these expectations
- block participants who repeatedly violate these expectations

Decisions are documented in writing in the relevant issue or PR thread when practical.

## Scope

This applies to all project spaces: GitHub issues, PRs, discussions, code reviews, commit messages, documentation, and any official communication channels.
