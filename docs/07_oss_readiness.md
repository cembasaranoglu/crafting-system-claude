# OSS Readiness

Crafting Kit includes OSS-facing files and templates, but public release still requires maintainer review.

## Included files

- `README.md`
- `LICENSE`
- `NOTICE`
- `CONTRIBUTING.md`
- `CODE_OF_CONDUCT.md`
- `SECURITY.md`
- `SUPPORT.md`
- `GOVERNANCE.md`
- `CHANGELOG.md`
- `.github/ISSUE_TEMPLATE/bug_report.yml`
- `.github/ISSUE_TEMPLATE/feature_request.yml`
- `.github/PULL_REQUEST_TEMPLATE.md`

## Before publishing

Review:

- license choice
- author and copyright
- repository URL placeholders
- security contact placeholders
- contribution process
- release version
- generated checksum file
- secret scan results
- plugin runtime test results
- official marketplace requirements if submitting the plugin externally
