# Contributor experience

A contributor should be able to answer:

- What does the project do?
- What is in scope?
- How is the project installed?
- How are tests run?
- What validation is expected before PR/MR?
- How are security issues reported?
- What kinds of contributions are not accepted?
- Where should design or compatibility questions be discussed?

A good contributor experience reduces maintainer load because expectations are visible before a PR or MR is opened.
