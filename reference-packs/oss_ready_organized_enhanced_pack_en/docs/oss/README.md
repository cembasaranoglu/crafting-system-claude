# OSS readiness docs

This directory contains policy, checklist and review documents for OSS readiness.

These documents focus on repository operations and public collaboration surfaces. They do not implement application behavior and they do not validate production readiness.

Recommended reading order:

1. `OSS_READINESS_CHECKLIST.md`
2. `OSS_READINESS_SCORE.md`
3. `VALIDATION_MATRIX.md`
4. `OPEN_SOURCE_RELEASE_GATE.md`
5. `SECURITY_RESPONSE_PROCESS.md`
6. `SUPPLY_CHAIN_POLICY.md`
