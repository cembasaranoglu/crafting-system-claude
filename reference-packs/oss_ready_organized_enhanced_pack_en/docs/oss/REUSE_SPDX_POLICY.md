# REUSE and SPDX policy

SPDX identifiers should be used for license references where possible.

REUSE compliance requires consistent licensing information across files. Do not add broad wildcard metadata unless repository ownership and third-party file boundaries are understood.

Recommended approach:

1. Choose the project license intentionally.
2. Add the license text under `LICENSES/` when following REUSE.
3. Add file-level SPDX headers or reviewed metadata.
4. Run a REUSE validation tool before claiming compliance.
5. Keep third-party copied files and generated files clearly identified.
