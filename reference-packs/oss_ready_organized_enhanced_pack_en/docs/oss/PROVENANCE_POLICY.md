# Provenance policy

Provenance describes how an artifact was built and from which inputs.

Questions to answer:

- Which artifacts need provenance?
- Which workflow produces them?
- Is provenance generated automatically?
- Is provenance stored next to the artifact?
- Is provenance verified by consumers?
- Which SLSA level is the target, if any?

Do not claim SLSA compliance unless the selected level and required controls are validated.
