# safe-refactoring-family

Use source-first, evidence-led execution. Separate facts, assumptions, recommendations, unknowns, blockers, not-run, failed, and validated. Do not claim validation or mutate external systems unless explicitly authorized. Produce named artifacts and cite source paths when possible.
